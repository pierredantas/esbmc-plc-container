# Where each number in the paper comes from

Paper: *ESBMC-PLC: Verifying IEC 61131-3 Ladder Diagrams with a Validated Translation to SMT-Based Model Checking*.
Paths are relative to the results archive `results-2026-10-24.tar.gz`, archived next to this source,
except those starting with `ESBMC_PLC/`, which are in this source tree under `paper/`.

Every ESBMC-PLC number comes from one build, fork commit `5efb80de72` (branch `pin/paper-2026-10-jumps`), over suite
release v1.2.0 (`6d1e3c3`); `single-build-2026-10-22/paper/PROVENANCE.txt` records it. An earlier run of both suite
routes, on October 18 with fork commit `03ad8f91af` over suite commit `d08e3f8`
(`route-runs-2026-10-18/PROVENANCE.txt`), enters only the last row of Table 4 and the run-to-run comparisons of §5.4
and §5.8. `reproduce-paper` regenerates
`paper/` and `routes/`; `reproduce-extra` regenerates `viac-900`, `viac-facts`, `deep`, and `rq4-repeats`. PLCverif,
NuSMV, and 2LS run outside the image (README, "Outside the image").

## Differences between the archived runs and the scripts

- The 900 s run on MATIEC's C ran in two parts. ESBMC's own `--timeout 900s` did not stop several runs of part 1, and
  the runner then set no limit of its own, so part 1 keeps only the 22 results that ended within 900 s, all UNKNOWN; part
  2 reran the other 103, and a watcher killed runs past 930 s (`reaper.log`). Any run longer than 930 s counts as a
  timeout. `run/viac_uniform.py` now kills ESBMC's process group 30 s after its limit, tested with a stand-in that
  ignores the limit.
- The facts run tried the force-flag facts and then the timer and counter facts together; the 5 counter programs proved
  in a second run with the counter facts alone (`recheck_separate_facts.tsv`). `run_facts.sh` tries force flags, then
  counter facts, then timer and counter facts, which reaches the same 117.
- PLCverif ran in four batches (Boolean pairs, timers, counters and edge blocks, the rest) with converter versions v2
  to v4 (`st_to_scl_v*.py` in each folder); the final results of each batch come from v3, and v4 adds only the witness
  mode, which produced `witness.tsv`. `run_plcverif.sh` runs all 208 in one batch with v4 and both block libraries.
- Absolute paths in the archived logs and records are rewritten: `$HOME` stands for the home folder, `$WORK` for the
  working folder under it, and `$TMPDIR` for a temporary folder. Paths to the scripts and the `reference` line of the
  generated deep-state benchmarks follow the script names of this source; nothing else in a record changed.
- `ws2/l1/scale_l1.py` used to leave ESBMC running after a timeout; the single-build rerun's scaling steps ran next to
  such processes. The RQ4 numbers of the paper come from the five repetitions with the fixed script, which also
  supports GNU `time` in the image.
